# Install Python
First, we need to install Python. This can be done most easily for Windows computers using the Microsoft Store. If this does not work, you may be able to take a manual approach, downloading directly from the Python website, though this may not be preferable.

If you already have Python installed on your computer or if you have Anaconda, we will provide direct instructions about how to work with this during instruction.

## Install Python in a Windows Environment with the Microsoft Store (Preferred)
The Microsoft Store can be used to easily install the latest version of Python directly, applying standard instal specifications. This can be done by opening the Microsoft Store, searching for Python, and installing the latest available version. At the time of this writing, that is v3.13.

## Manually Install Python in a Windows Environment (Not Preferred)
1. Navigate to [https://www.python.org/](https://www.python.org/) and download the latest fully released (not preview) build.  At the time of this writing that is v3.13.2.

## Confirm Python Installation

Open Terminal/Powershell and type  `python` and hit enter. This should open a command-line Python interpreter which should look similar to the image below.
