# Install Python in a Windows Environment
Navigate to https://www.python.org/
## Download the latest fully released (not preview) build.  At the time of this writing that is v 3.13.2.
Run the exe and make sure to ***check the box to Add python.exe to PATH***
![image](https://github.com/user-attachments/assets/bf676366-1017-4549-9d06-f21e3bb4e0b1)

Next, select Customize installation and leave the defaults checked as below. 
![image](https://github.com/user-attachments/assets/98c9517c-e7f3-4287-bdab-ca46b1aa5682)

Select ***Next***
Edit the filepath to the root of C if you have permissions to do so and click ***install***
![image](https://github.com/user-attachments/assets/f9af9605-062e-4519-a996-837411434a8a)

## Confirm Python Installation

Open Terminal/Powershell and type  ***python*** and hit enter

![image](https://github.com/user-attachments/assets/924707ca-bcba-41be-9c2e-c51a99d7c06a)

Tha above image is an example showing a successful Python installation
